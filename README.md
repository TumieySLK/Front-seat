# Front Seat

Front Seat is a mobile-friendly taxi payment tracker for the front-seat passenger of a minibus taxi. It helps record passenger payments, calculate fares and change, track change owed, and keep track of the 15-seat capacity.

![Screenshot of the app](images/screenshot.png)

Live demo: YOUR-NETLIFY-LINK-HERE

## Features

- Select a taxi route and view the fare
- Record the row, number of people, and amount handed over
- Calculate the amount due and change
- Track payments made during the trip
- Track change that still needs to be given
- Mark change as given
- Display seats paid and seats remaining
- Display total fares collected and total change owed
- Show when the taxi is full

## Usage

1. Select a taxi route.
2. Select the passenger's row.
3. Enter the number of people.
4. Enter the amount handed over.
5. Click Submit to record the payment.
6. The app calculates the amount due and any change.
7. If change is owed, it appears in the Change Owed section.
8. Click Change Given when the change has been handed to the passenger.
9. The trip summary updates as payments are recorded.
10. When 15 seats have been paid for, the app displays "Taxi full, let's go"

## Known Issues and Next Steps

- The app currently focuses on one taxi trip at a time.
- A future version could save trip information so that it is not lost when the page is refreshed.
